# Class Scheduling System

Final project for Web Systems Technologies by JM Jagorin.

A web-based CRUD application for managing class schedules, built with PHP, MySQL, HTML, CSS and Bootstrap 5.

## Features
- Add, view, edit and delete class schedules
- Search by subject, instructor, section or room
- Room conflict detection for overlapping times

## Setup (XAMPP)
1. Copy the project folder to `C:\xampp\htdocs\`
2. Start Apache and MySQL
3. Import `database.sql` in phpMyAdmin
4. Open `http://localhost/Jagorin_JM_ClassSchedulingSystem/`
